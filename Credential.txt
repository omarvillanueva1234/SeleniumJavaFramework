How to run?
1. Once all dependencies are downloaded by maven, go to test->java->BaseFolder->Tests->TokenTest
2. Right click the TokenTest class (the name) then More Run/Debug -> Modify Run Configuration.
3. In the Configuration tab, Go to Test kind -> Select Group in the dropdown
4. Under JDK Settings, VM Options: paste the Java Run Configuration (-ea -Denv=dummy -Dargs=username=emilys,password=emilyspass)
5. Click Ok or Run
